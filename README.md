# P-Player

P-Playerは、ProtoPediaなどへ掲載する記事を、プレビューを見ながら作成できるHTMLエディターです。
見出し、本文、画像、動画、表、目次、Before / Afterなどのパーツを組み合わせ、完成したHTMLをコピーして利用できます。

## すぐに使う

1. GitHubの「Code」→「Download ZIP」からファイルをダウンロードします。
2. ダウンロードしたZIPを展開します。
3. 展開したフォルダ内の `index.html` を、Google ChromeまたはMicrosoft Edgeで開きます。

`index.html`だけを別の場所へ移動しないでください。動作に必要なJavaScriptと`vendor`フォルダも同じ場所に必要です。

## 基本的な使い方

1. 画面上部の「パーツ追加」から、見出しや本文などを追加します。
2. プレビュー内の文章を直接編集します。
3. パーツを選択し、設定画面から色、サイズ、余白、デザインなどを調整します。
4. 作業途中の記事は「名前を付けて保存」でJSONファイルとして保存します。
5. 完成後に「HTMLをコピー」を押し、ProtoPediaの記事編集画面へ貼り付けます。

後から編集を続ける場合は、保存したJSONを「記事を開く」から読み込んでください。P-Playerで出力したHTMLを読み込んで再編集することもできます。

## 保存について

- JSON：P-Playerで再編集するための記事データです。編集を続ける場合はこちらも保存してください。
- HTML：ProtoPediaなどへ貼り付けるための出力です。
- 自動保存：使用中のブラウザ内に保存されます。別のPCや別のブラウザには引き継がれません。

大切な記事は、自動保存だけに頼らずJSONファイルでもバックアップしてください。

## 画像・動画・外部サービス

YouTube、XなどのURLを使用したパーツは、表示時に各サービスへ通信します。インターネットへ接続していない場合や、提供元の仕様が変わった場合は表示できないことがあります。

## 開けない場合

通常は`index.html`を直接開くだけで使用できます。ブラウザの制限で一部機能が動かない場合は、展開したフォルダでローカルサーバーを起動してください。

Pythonがインストールされている場合の例：

```powershell
python -m http.server 8000
```

その後、ブラウザで <http://localhost:8000> を開きます。

## フォルダ内のファイルについて

- `index.html`：P-Player本体
- `security.js`、`external-services.js`、`vendor/`：動作に必要なファイル
- `tests/`：開発者向けの自動テスト。P-Playerを利用するだけなら触る必要はありません
- `SECURITY.md`：セキュリティに関する説明
